# Conecta Elas

Protótipo interativo sobre mulheres na tecnologia, com narrativa curta, profissionais, projetos e conversas fictícias e o minigame **Descubra seu Universo**.

## Executar localmente

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

`npm run build` gera a versão de produção; `npm run preview` a serve localmente. `npm run test` executa os testes automatizados.

## Experiência

- Sete capítulos sobre Ada Lovelace, Hedy Lamarr, Grace Hopper e Dorothy Vaughan, a proposta do Conecta Elas e os próximos passos.
- Atalhos na abertura para pular a narrativa, conhecer profissionais fictícias e abrir diretamente o minigame.
- Navegação por menu, teclado, setas e indicadores, com controles responsivos e respeito a movimento reduzido.
- Áreas demonstrativas focadas em tecnologia: software, dados e IA, engenharia e robótica, design digital e cibersegurança.
- Busca e filtros em perfis, projetos fictícios e conversas locais. Mensagens não são enviadas a pessoas reais.
- O minigame explora afinidades; não define vocação, capacidade ou recomendação profissional. Respostas ficam apenas na memória da sessão.

## Escopo e fontes

Perfis, projetos e conversas são fictícios. O site não tem cadastro persistente, autenticação, contato profissional real, publicação, moderação ou oportunidades confirmadas. Uma comunidade real exige consentimento, privacidade, moderação, segurança e salvaguardas adequadas para menores.

As biografias e os créditos de imagem das pioneiras aparecem junto aos conteúdos. As fontes estão também listadas em [documentação de experiência, escopo e referências](docs/UX-ETICA-AVALIACAO.md). Retratos são imagens de arquivo e não representam estudantes atuais.
